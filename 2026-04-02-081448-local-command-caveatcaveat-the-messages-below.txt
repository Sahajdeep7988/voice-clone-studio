## PHASE 1 — AUDIO PREPROCESSING (core/preprocessing.py)                        
                                                                                
Reference Applio's preprocessing approach before writing this.                  
                                                                                
Build class AudioPreprocessor with method:                                      
process(file_paths: list) -> dict                                               
                                                                                
Steps:                                                                          
- Accept: MP3, WAV, FLAC, MP4, MKV                                              
- Step 1: FFmpeg → extract and convert to 16-bit WAV at 44.1kHz                 
  → save to dataset/raw/                                                        
- Step 2: Demucs (htdemucs model) → isolate vocal track                         
  → save to dataset/vocals/                                                     
- Step 3: WebRTC VAD (aggressiveness=3) → split into segments,                  
  discard any segment under 1.5 seconds → save to dataset/segments/             
- Step 4: Calculate total duration.                                             
  If under 5 minutes → raise PreprocessingError with message                    
  "Dataset too short: minimum 5 minutes required"                               
- Step 5: Return quality report:                                                
  {                                                                             
    "segment_paths": [...],                                                     
    "total_duration_minutes": float,                                            
    "segment_count": int,                                                       
    "quality_label": "Poor|Acceptable|Optimal"                                  
  }                                                                             
  quality_label: <10min=Poor, 10-20min=Acceptable, >20min=Optimal

## PHASE 2 — LLM HYPERPARAMETER CONFIG (core/llm_config.py)                     
                                                                                
Build class LLMConfigurator with method:                                        
get_hyperparameters(dataset_stats: dict) -> dict                                
                                                                                
Steps:                                                                          
- Step 1: Scan hardware                                                         
  VRAM: subprocess nvidia-smi or rocminfo                                       
  RAM: /proc/meminfo                                                            
  CPU cores: os.cpu_count()                                                     
                                                                                
- Step 2: Build prompt for Gemma 3 1B running locally via Ollama                
  at http://localhost:11434                                                     
  Send hardware + dataset stats as JSON context.                                
  Instruct model to return ONLY this JSON, nothing else:                        
  {                                                                             
    "batch_size": int,                                                          
    "epochs": int,                                                              
    "learning_rate": float,                                                     
    "save_every_n_epochs": int                                                  
  }                                                                             
                                                                                
- Step 3: Validate with strict schema. Enforce safe limits:                     
  batch_size: 1 to 32                                                           
  epochs: 100 to 1000                                                           
  learning_rate: 0.00001 to 0.001                                               
                                                                                
- Step 4: If Ollama fails OR JSON invalid → rule-based fallback:                
  VRAM >= 8GB: batch=8, epochs=500, lr=0.0001, save_every=50                    
  VRAM >= 4GB: batch=4, epochs=300, lr=0.0001, save_every=50                    
  else:        batch=2, epochs=200, lr=0.0002, save_every=25
